# Histórico

Arquivo morto **consultável**. Nada que sai do `CLAUDE.md` ou do `STATUS.md` é apagado:
vem para cá.

```text
history/
  README.md                  este arquivo
  sessions/                  um registro curto por sessão/etapa (AAAA-MM-DD-EXX.md)
  claude-md-archive/         trechos removidos do CLAUDE.md (AAAA-MM-DD.md), com motivo
  status-archive.md          itens antigos de "Concluído" do STATUS (criado quando necessário)
```

Regras:
- Arquivos daqui **não** são lidos no início de sessão. Só sob demanda.
- Cada trecho arquivado indica: data, de onde saiu, por quê, e o que o substitui (se algo).
